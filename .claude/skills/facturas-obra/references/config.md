# Configuración (editable)

## Formato de nombre de archivo
PENDIENTE – el usuario lo indicará. Cuando lo dé, anótalo aquí como patrón, p. ej.
`{fecha:AAAA-MM-DD}_{proveedor}_{importe}_{proyecto}.pdf`, e indica separador, formato de fecha e importe.

## Carpetas
- Raíz: PENDIENTE (carpeta del escritorio que indicará el usuario).
- Estructura: `Trimestre 01 … Trimestre 04` / `<Proyecto>` / archivo.
- Trimestre según fecha de factura: T01 01-ene–31-mar, T02 01-abr–30-jun, T03 01-jul–30-sep, T04 01-oct–31-dic.
- ¿Carpeta de año por encima (p. ej. `2026/Trimestre 01`)? PENDIENTE – preguntar si las facturas abarcan más de un año.
